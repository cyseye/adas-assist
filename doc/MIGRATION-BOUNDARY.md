# 资产与运行边界

本仓直接改造根资产，仅适配 Codex，不维护独立 package、安装器、回执或导出清单。

| 路径 | 职责 |
|---|---|
| skills/ | 技能、共享协议与确定性文件工具的唯一维护源 |
| commands/ | 按需读取的流程入口，路由至技能正文 |
| agents/ | 角色职责与交接契约，非原生角色注册 |
| standards/ | 本仓标准与安全规则 |
| .agents/skills/ | 指向根技能的相对软链接，供 Codex 发现 |
| memory/、decisions/ | 本仓记忆与决策；索引与正文分工 |
| doc/ | 设计、验证记录与待验边界 |
| .adas-assist/ | 本地任务状态等运行数据，不入库 |

维护时直接编辑根源，不复制技能，也不从宿主全局目录回退取正文。改入口或迁移前检查在途内容；未知副本与用户配置不得自动覆盖。本次 os 任务脚本和行为测试保留到 skills/os，独立分发专用代码及测试退出维护。

技能文件和链接可访问只证明文件条件满足；真实宿主发现、调用及业务结果仍分别验收。原始记忆、凭证与本机配置不作为公开交付内容。
