# skill 运行时公共约定

本仓仅面向 Codex。技能、共享规则、角色和工具以仓内正文为准，按 AGENTS.md 定向读取。文件存在不代表原生能力已注册。

## §0 执行与数据边界

- 采集、召回、评估和清理均为本次任务内的显式步骤，不安装自动事件或后台任务。没有数据记 no_data，未执行不记通过。
- 默认不生产 metrics.latest.json 或全局调用日志。只有当前验收要求指标时才按对应模板记录，并注明来源与口径；技能旧步骤中的指标字段按此规则消费。
- 文件工具需要显式输入。共享状态工具同时传 `ADAS_ASSIST_ASSET_ROOT=<本仓绝对路径>` 和 `ADAS_ASSIST_DATA_ROOT=<隔离数据根绝对路径>`，缺失或不成对即拒绝，不回退宿主目录。变量只服务本地路径。
- memory/MEMORY.md、decisions/KNOWLEDGE.md 是本仓索引；按命中读取正文。记忆与决策维护遵循 AGENTS.md 的归口，不复制正文或访问隐藏宿主记忆。

## 帮助入口

独立参数 help / 帮助只说明功能、输入、产物、示例和限制，不执行任务。无目标先明确目标。命令见 [os](../../commands/os.md) 与 [evolve](../../commands/evolve.md)。

## §1 目录与产物

任务目录默认为 cwd；中间产物写任务专属 `.build/<skill>/`，运行状态写显式数据根下 `.state/`。最终产物按项目约定保存。清理前核引用、活跃任务和保留要求，只处理本批可重建文件。

## §2 指标

记录实际执行、静态检查、未运行及失败；指标附分子/分母、来源、时间窗和排除项。没有真实用量则未知，不估算费用。具体证据判据见 [assessment-protocol](assessment-protocol.md)。

## §3 生命周期与失败

交付物保留；中间产物在无消费者和保留要求后定向清理。输入、必要证据或能力缺失时停止依赖动作并保存恢复点。角色输出不合规让原角色重发一次，仍失败则待验。限流时降并发、有界重试，不换账号或无限循环。

## §4 agents 调度

使用当前工具支持且获授权的代理类型，先读取角色职责、输入输出及写域；Markdown 名称不自动注册。必要独立评审须有真实独立上下文，不以主控自演替代。

委派只传必要输入，正向列明文件范围；重叠写域串行。PCF 摘要/JSON 交接见 [pcf-execution-flow](pcf-execution-flow.md)，其他回传见 [io-protocol](io-protocol.md)。失败逐条对应任务，不按返回顺序猜测来源。

## §5 恢复与接力

关键节点更新项目既有记录：目标/授权、源与变更、检查与证据、决策、未决和下一步。恢复先核真实工作树及证据时效，定向复验，不凭旧 done 追认。不得推定压缩前会自动保存。

## §6 精简

入口只保留稳定路由，正文按需读取；计数和验收快照写任务记录。改动后核入口行数、引用与直接消费者，保留其他在途改动。不得以整树干净作为验收门。
