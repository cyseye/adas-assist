# 效果评估的最小闭环

本仓人工评估协议，供 effect-governance 使用；不实现后台统计、账单读取或自动进化。

## 证据链审计清单

每个结论记录对象/范围、基线、判据、输入与实际输出、证据路径、反例、限制及下一步。真实性硬门以 analysis-methodology 为准；JSON 格式或哈希一致不证明业务正确。

- 有同口径的前后/正反数据才判断改进；无数据为 no_data，不写“零问题”或收益百分比。
- 记录失败、未运行和不利结果，不能只展示通过样本。
- 用量不可读取则未知，不从文本长度估算费用。跨任务或宿主外推单列未验证边界。

## 置信度与对抗验证调度

| 证据状态 | 处理 |
|---|---|
| 可复跑的直接证据，含已知正/负对照 | 限当前样本结论，明确覆盖分母 |
| 静态推断或部分数据 | 标中/低置信度与未测范围 |
| 无证据、来源缺失或协议冲突 | no_data / 待验，不签通过 |

产物规范验证走 decision-verify；交付收尾走 finish-check；方案裁决走 PCF；体系机制争议走 devils-panel。角色与独立性遵守 pcf-execution-flow，不以自演冒充独立复核。

## 指标口径

先声明分子/分母、时间窗、来源和排除项，再给读数。风险定向抽样不称随机漏检率。仅人工复盘的指标无自动采集保证，写入义务以 runtime-conventions 的当前宿主约定为准。
