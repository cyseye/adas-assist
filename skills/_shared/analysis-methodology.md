# 分析方法论（六步流程）——分析类任务参考协议

> 主控接分析类任务（体系分析 / 方案评估 / 问题诊断 / 重构压缩 / 技术调研……）时 Read 本文件参考。**参考协议非硬门控**：按任务规模裁剪——小分析可只走 1→3→6，大分析全六步；每步有产物。

| 步骤 | 做什么 | 要点 |
|------|--------|------|
| 1 只读盘点 | 不动手先摸底：建量化基线（规模统计 + diff / 增量） | 先有基线数字，证实问题方向与量级，不凭印象开题 |
| 2 骨架+重点流程 | 画结构：ASCII 骨架 + 核心流程 | 先结构后细节；图为分析导航用，非交付物、非任务编排 |
| 3 逐项分析 | 并行取证，逐项量化，分类判定 | 结论挂在证据上；区分实质问题与表观现象；取证按对象分层——文本 Grep、代码结构用 ast-grep skill（AST 等价即命中，不误报注释/字符串）；处置选型见 `_shared/pattern-router.md` |
| 4 多轮推衍 | 多方案对照（激进 vs 稳健）→ 对抗批评 → 修正判定 | 批评可推翻原判定，留痕不静默改口；立场收敛即停，不为形式完整凑轮次；分歧不可收敛时走 decision-consensus 多轮收敛后留痕 |
| 5 验算 | 执行前核验关键假设；执行后数字复扫，对照第 1 步基线 | 验算双侧夹住执行；复扫与取证同层选工具 |
| 6 任务清单 | 结论分级处置：直接执行转编号任务清单（T1-Tn），降级保留 / 仅登记不动 | 用户确认门控后才执行；每项可溯源到分析证据 |

**沙盘推衍（重大方案/机制改动适用）**：第 4 步的实证强化形态——并行 spawn 3 视角（效率=拿真实场景走新流程验证拦截率 / 对抗=攻击失效面与误伤 / 体系=断链与双写核查），每视角**必须走 ≥1 个真实历史场景**（抽象辩论不算数），输出拦截率/失效面/修正建议，主控裁决定稿。

跨步骤通用原则：

- **数字与证据说话**：开题有基线、判定挂证据、收尾对基线

## 证据链硬门（结论准入，2026-09-15 用户裁决升格为底层纪律）

任何进入结论/ADR/配置表的判定，必须满足以下准入，否则一律降级为"假设"不得出场：

1. **逐结论溯源**：每个结论可指认唯一落盘数据件（文件/JSON/SQL 结果）；"X 优于 Y"必须能按 run/样本级数据复算——复算不出来的表述删掉
2. **预测预注册**：质量/退化/甄别类判定所依赖的预测清单，必须在见到数据前落盘（含黄金标准）；事后解释不具证据资格
3. **阳性对照先行**：评分器/检测器/扫描器先证明能区分好与坏（注入已知缺陷证信号可触发），再信其对未知对象的零信号或满分
4. **推断显式标级**：外推/插值/单事件锚点一律标 confidence=M/L 并注明未测边界；跨域外推（如小前缀→大上下文、实验档→生产档）默认断裂除非有桥接数据
5. **不利数据不得选择性弃用**：弃用须给机制性理由（污染源+复现路径），被弃数据的存在与理由进留痕
6. **无数据即假设**：无溯源件的判定进 PENDING 观察池，不进 ADR；"我感觉/应该是"禁止出现在裁决文本
7. **外源证据规则（本仓改写）**：本仓未配置外部检索通道。凡判定依赖外部事实（版本号/API 现状/库维护状态/时价）而仓内无落盘数据可复算时，一律 confidence=低并显式标注「无外检通道」；不得凭模型内在知识断言时效性内容。若宿主环境提供内建 WebSearch，可按原规则取证（URL+取文日期+关键句引文；未快照落盘 confidence 封顶 M），否则该项判定悬置进 PENDING 观察池。本仓未包含原三规则全文（快照/注入隔离/消费强制点）。

## 回归集与出题纪律（2026-09-19 议题2 轮3 补订；纪律条款非机制）

1. **五字段 case 卡**：新增回归 case 须带五字段——instruction / verifier 断言（确定性判定，弃 LLM-judge）/ 数值容差显式声明 / difficulty / 来源指针；存量 case 不强制回填（登记观察）。
2. **泄漏审计准入**：回归 case 描述不得与被测 skill 正文共享关键解法句（周评 checklist 项，非硬门——防假纪律）。
3. **分域差值强制**：skill 增益结论必须报分域/分 case 差值，禁只报均值（SkillsBench 16/84 负 delta 被均值掩盖的教训锚定）。
4. **出题查库先行**：对照实验出题前先查 `registry/exam-bank.jsonl`（并行 agent 建的种子库），无可用题才自撰；自撰题实验后若已验证可回收进库（题面+期望判定+来源指针+日期）。
5. **作者效应对冲**：一次性外部出题防作者效应为既有护栏（model-routing ADR）；题库是它的低成本前置，不是替代。
6. **区分度与可判定分立**（终判全文锚 `.build/exam-bank-first-consumption-20260919.md`）：可判定性已验证≠有区分度；**写作式考卷在本消费 harness 内不产生档间区分度**，题库定位=底线回归锚+出题纪律训练素材，区分度载体=机械断言型回归集（判卷者=脚本非模型）。重启区分度探索前置=独立判卷者+过程日志评分；出难题四方向保留（数值陷阱/模糊判据/对抗审查/交叉比对）。
