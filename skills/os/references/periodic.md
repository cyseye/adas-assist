# 轻量周期规则

v1.0 只交付检查方法和频率建议，不安装 cron、launchd、宿主自动任务或后台 agent。用户本次要求迁移规则不等于授权长期驻留。检查完全可以手动完成。

| 事件/建议频率 | 消费者与动作 | 结果 |
|---|---|---|
| 修改协作资产后 | 维护者运行受影响技能与共享测试 | 记录通过、失败与待验 |
| 重要任务完成/接力前 | 任务负责人核验收、证据与未决 | 更新原任务文件 |
| 活跃维护期每周可选 | 维护者复核阻断任务和失效证据 | 只更新必要状态，不自动立项 |
| 升级宿主版本后 | 维护者执行Codex smoke | 记录真实发现/调用结果 |

仓库检查命令见 [质量清单](quality.md)，检查任务文件行为和共享契约；任务完整性可手动运行 task.py status（只核声明范围的文件哈希）。这些检查不判断业务完成、模型质量或费用，不替代真实宿主验收。

以后确需自动化时只接宿主/操作系统既有调度器。单个任务先明确：负责人、授权范围、时区与频率、输入输出、超时、互斥、失败记录、暂停与删除方法。先手动成功，再做隔离试运行；配置在位、调度已加载、实际触发、业务成功四种证据分别记录。

高成本语义复核按信号触发，不默认每天跑模型。模型余额不足/能力缺失时记录跳过及原因，不暗换账号或无限重试。自动执行不得扩大任务范围或带出私有原文。此版本没有实现自动调度器，也没有定时业务验证结果。
