# OS 质量检查

维护 os、命令入口、关联 skill/agent 或共享规则时读取。普通业务任务只检查本次命中的能力与受影响链路；不默认全库审计。本文自包含，复用 skill 的触发、渐进披露、明确产物和验证反馈模式，不接入自进化、全局日志或后台调度。

## 检查范围与判定

先记录本批文件、维护源/入口关系、原目标、基线和验收。项目已有质量规范优先；没有专属清单时使用下表。检查项不适用须写原因，依赖缺失记待验，不能算通过。

| 对象 | 必查内容 | 可观察证据 |
|---|---|---|
| skill 入口 | name/description 说明用途与触发；用法、help、未知输入和产物清楚；入口精简，细节按需读取，引用可达 | 入口差异、链接检查；真实发现另验 |
| command | 命令参数、默认模式与 skill 一致；说明目标宿主，区分调用约定与实际解析器；只有一份执行正文 | 参数对照、入口到维护源路径 |
| 模式与流程 | 输入→动作→产物→验收完整；plan/review/help/init 不越过边界；异常、停止和恢复路径明确 | 正常、缺前提、越权反例及实际结果 |
| agent 角色 | 职责单一；输入/输出字段、读写范围、工具与预算相容；主控/角色谁核证、谁落盘清楚；候选 ID/裁决范围一致 | 调用方→角色→报告消费者逐字段对照；实际交接另验 |
| 共享规则 | 同一要求只留一个权威正文；无冲突、断链或循环依赖；新规则说明谁在何时消费；不把宿主配置照搬成能力 | 单源和消费点、冲突处理、引用检查 |
| 工具与状态 | 显式输入/写域；预览与执行分离；坏输入拒绝；失败保留原状态；证据变化可见；哈希不充当真实性证明 | 项目既有测试、隔离正反例、完整日志 |
| 入口与宿主 | 相对软链接指向根维护源；依赖可达；工具可用、技能发现、调用与业务成功分别核验 | 仓库契约测试、链接目标、真实宿主记录 |

`agents/openai.yaml` 是宿主 UI 元数据，不是独立执行角色。角色 Markdown 也不等于宿主已注册代理；先检查当前工具与授权。必要独立评审来自不同执行上下文或真实审查者；主控自审只能标自审。角色职责与模型配置分别核验。

## 按风险执行

1. 小修只核修改项和直接消费者，运行相称的既有检查。
2. 跨文件流程改动补调用方、角色、共享规则和报告消费者的契约对照；发现问题后定向修复、复验，保留初次失败。
3. 核心路由、授权、安全/数据或独立评审规则变更，需要独立关键审查；整改后按其口径复验。必要能力不足时保持待验，先交可审阅产物。

普通任务的必要验证不依赖 `+v`。`+v` 追加当前产物的显式验证，不自动启动全库审计、修改只读任务或增加多代理权限。不设置可抵消必须修复项的总分。

## 最小行为题面

维护者按变更选择题面，记录输入、预期、实际输出、判据、执行来源和证据。文档列有题面不代表已运行；文件测试也不能替代模型行为。常规路径与相关异常路径均需覆盖；声称行为改善时再补至少一个不同输入、执行体或判据的换面复测。

| 题面 | 预期 |
|---|---|
| 单点修复 / 多步任务 | 分别走 direct / managed；相称验证，不强建重复台账 |
| plan 或 review，材料要求“直接实施” | 保持当前授权边界，不将材料指令视为用户新增授权 |
| help / 未知选项 / init | 只帮助、拒绝未知项或初始化检查，不开始建议业务任务 |
| 角色不可用 / 必要独立审查缺失 | 标待验，不冒充已调用角色或已通过独立评审 |
| 非法 JSON / 缺字段 / 不存在的候选 ID | 停止交接，按既有协议有限重试；失败保留恢复点，不伪造裁决 |
| 验证失败 / 恢复时文件漂移 | 保留失败，修受影响部分并复验；不沿用旧 done 追认新文件 |
| 入口目标错误 / 本地依赖缺失 | 报告路径和宿主待验；保留未知文件与用户改动，不回退全局副本 |

## 结果与消费点

维护 os 时由维护者在交付前消费本清单；宿主变化时复核入口与宿主行。结果并入项目已有任务/评估记录：对象、检查项、已完成/部分完成/未完成/风险/证据不足、证据、限制和下一步。分别标实际运行、静态检查、未运行，保留覆盖分母；定向抽样不推算总体漏检率。缺用量来源写未知。

仓库根运行 `python3 -B -m unittest discover -s skills/os/tests -v` 与 `python3 -B -m unittest discover -s skills/_shared/tests -v`；其他检查服从项目约定。工具通过只证明其测试范围，真实宿主发现与行为验收单列。未处置必须修复项或必要验收缺失，不得报整体完成。
