# 安全协议：数据分级与外发栅栏（security-protocol）

> 定版 2026-09-20（ADR security-governance-blueprint-20260920）。单源：数据分级/外发规则/敏感模式集，他处引用本表勿复制。G1 hook 上线须用户批准 settings 变更（治理红线例外条款）。

## 数据分级（底层协议）

| 级 | 定义 | 例 | 外发规则 |
|---|---|---|---|
| **L0 公开** | 已公开信息/不含内部拓扑 | 开源项目名、公开文档 URL、通用技术问题 | 自由出网 |
| **L1 蒸馏后可出网** | 内部事实的结构化抽象 | 「内部系统划分为 3 个服务」（不带 IP/端口/路径） | 脱敏为拓扑占位符后出网 |
| **L2 仅本地** | 内部拓扑/凭证/原始数据/画像原文 | 内网 IP(192.168.x/10.x)、端口映射、`~/.claude` 内路径、.env/Bearer/sk-/ghp_ 串、memory 原文、纠偏记录 | **禁出网**（检索 query、fetch URL、探索 prompt、git push 四通道全禁） |

原则：出网内容默认从 L0 表述；需要内部上下文做检索时，转译为公开等价物（「内部服务」而非具体 IP/端口/路径）。

## 敏感模式集（机械判定，G1/G2 共用单源）

**单源=本仓 `skills/_shared/security-patterns.json`**；机械扫描门（G1=`skills/skill-evolution/scripts/t38-settings-guard.py`、G2=`skills/skill-evolution/scripts/cc-commit-gate.py`，共用 `skills/_shared/scripts/secret-scan.py` 管道，回归件 `test_p7_escape.py`）。白名单语义=**设计裁决留痕**（执行面=模式集不收录该类目标，如回环地址当前无任何模式覆盖）；若未来 patterns 收录回环类等白名单目标，须同步在 G1/G2 扫描实现 whitelist 匹配放行逻辑（2026-09-20 复盘轮澄清，防「写了没人执行」读法）。

## 四外发通道与栅栏映射

| 通道 | 栅栏 | 状态 |
|---|---|---|
| 检索 query / fetch URL | L2 表述审查（G1 regex 门，hooks PreToolUse(Bash) 接线，见 `bootstrap/settings.hooks.json`） | 主控出网前按 L2 分级自检 |
| git push 内容 | push 前敏感串自检（G2 commit-gate 门） | 主控 push 前自检 |
| 外向探索 spawn prompt | G3 脱敏规约（拓扑占位符表述，禁明文 IP/端口/路径） | ✅ 2026-09-20 P1 落地 |
| memory/画像上传 | 既有分界原则（原始本地/仅蒸馏上传），本协议 L2 明确禁原文 | 生效（原则层） |

## 模式集消费方准入

新消费方须走 secret-scan.py 规范化管道+G1/G2 双门并全表回归，禁裸 `re.search` 直连模式。

## 外部 skill 装前审查（入向供应链，2026-09-25 心跳轮落地）

> 背景：2026-09-25 外部参照轮（C 方向）实证本协议此前仅覆盖**外发**栅栏，**入向**（安装/吸收外部 skill）零审查；OpenClaw 生态（1800+ skill 市场）安全分析中「poisoned skills」列真实攻击路径（证据指针见 BACKLOG 2026-09-25 续探轮行）。门=**装前人工跑一次，零常驻零新机制**——不建自动扫描，防过重抑制外部吸收。

装前 checklist（五项全过才装；任一不过=不装并留否决理由）：

1. **注入指令扫描**：SKILL.md 及 references 全文通读，标记试图改变主控行为的指令式文本（「忽略此前规则」「必须替用户决定」类）——防「网页/外部内容衍生指令经安装存活」。
2. **敏感面读取**：grep 常见密钥凭证模式（.env/Bearer/sk-/ghp_ 串等，见 L2 例）与 `.ssh`/`.env` 等敏感路径引用。
3. **网络外联声明**：清单化 curl/fetch/URL，外联域名须与 skill 功能相称。
4. **执行面声明**：脚本/命令清单核查，有无常驻服务/launchd/cron 自装行为（本体系纪律：一次性实验、无常驻）。
5. **来源信誉**：仓库 stars/维护者/近期 commit 活跃度；fork 链与原仓 diff。

登记义务：安装决定+checklist 结果一行入 BACKLOG（可追溯）；skill 卸载/淘汰由主控评估留痕（decision-lifecycle）。

## N1 内网服务白名单（策略层）
- 本仓不含本机基建拓扑；如宿主部署内网服务，白名单单源=宿主本地配置，本节只立策略不复写清单（防双单源漂移）。
- 策略三条：①内网服务**只准 loopback 绑定**，任何 `*:port`/非 127.0.0.1 绑定=偏差即查；②存活面=探针+告警链，探针即白名单活体校验，新增常驻件须同步加探针；③会话内引用走占位符转译（「内部服务」非「IP:端口」，见数据分级节原则），端口拓扑禁进外向 prompt/query。

## 存量清洗（T2 收口，2026-09-20 P0 登记）

git 跟踪文件中的 L2 内容清单与清洗进度见 BACKLOG 对应任务；清洗原则=拓扑信息降为占位符、凭证指引降为「见本地 .env」、IP 段删除。清洗后 G2 扫描应零命中。

## 回顾与演练

每阶段收口走 decision-improve 复盘；P3 红队攻防演练双指标=「拦得住（L2 带出尝试 ≥90% 被拦）+ 不误伤（正常外发 ≤5% 误拦）」；周评估挂安全对账行（G2 拦截次数/误伤数/G1 待批状态）。

P3 首轮演练结果（2026-09-21，T16 闭环）：红队 3 路攻防（命令面/内容面/守方复验）——首轮击穿 13 向量，当轮修复 12 项（sh -c 包装/alias 逃逸/-m 分段拼接/引号失衡 fail-open 收窄/编码阈值 b64≥12·hex≥24/跨行重组/URL 解码/NFKC/textconv 模式/home-path 去尾斜杠/G1 全参数遍历/留痕截断 500），复验 10/10 payload 全拦+全仓 210 文件 0 误伤+sha256/自指 6 项阴性——**双指标达标（拦 100%≥90%、误伤 0%≤5%），蓝图 ADR 推翻条件不触发**。残留登记 BACKLOG（symlink 120000 识别/-F stdin/core.editor 消息面/history-scrub 存量工具）。
